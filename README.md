# Дедлайнатор

Небольшой веб-планировщик учебных задач для командного проекта по программной инженерии. Проект нужен для практических работ по Git, Wiki, планированию и локальному CI/CD.

## Возможности

- список задач с датой, приоритетом, командой и описанием;
- доска со статусами «Бэклог», «В работе» и «Готово»;
- локальное хранение задач в JSON;
- HTTP API для просмотра и изменения задач;
- автоматические тесты без сторонних библиотек.

## Запуск

Требуется Python 3.10 или новее.

```powershell
py -3 scripts/seed_demo_data.py
py -3 src/server.py
```

Первая команда заполняет пустую установку десятью учебными задачами и сохраняет уже существующие пользовательские данные. Откройте <http://127.0.0.1:8000>. Рабочие данные хранятся локально в `data/tasks.json`, который не попадает в Git.

## Проверка

```powershell
py -3 -m unittest discover -s tests -v
```

## CI/CD

- [GitHub Actions](.github/workflows/ci.yml) проверяет код и запускает тесты при отправке изменений.
- [Локальная сборка GitHub Actions](.github/workflows/local-runner.yml) запускается вручную на Windows runner с меткой `deadlineator`: проверяет код, запускает тесты и сохраняет архив приложения.
- `.gitlab-ci.yml` — вариант конвейера для GitLab.
- [`gitflic-ci.yaml`](gitflic-ci.yaml) — три стадии GitFlic: проверка/компиляция, модульные тесты и подготовка локального релиза на Windows Runner с тегом `local-windows`.
- `ci-verify.sh` выполняет сборку и тесты; `ci-deploy.sh` готовит копию релиза в каталоге `deploy/releases`.
- GitFlic Runner использует Shell executor с Git Bash и Python 3.12 из профиля пользователя Windows. Конвейер выполняется локально на этом компьютере.

Подробности о продукте, архитектуре и командной работе находятся в каталоге [`wiki/`](wiki/Home.md).
