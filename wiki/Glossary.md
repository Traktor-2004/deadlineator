# Термины

| Термин | Значение |
| --- | --- |
| CI | Автоматический запуск проверок при изменении кода |
| CD | Автоматическая доставка проверенной сборки |
| Runner | Агент, который выполняет задания CI/CD на компьютере |
| Issue | Карточка задачи в системе управления проектом |
| Milestone | Группа задач с общей целью и сроком |
| Self-hosted runner | Агент CI/CD, установленный и запускаемый на своём компьютере |

## Сокращения в примерах

- **DoD** — Definition of Done, критерии завершения.
- **API** — интерфейс, через который части программы обмениваются данными.
