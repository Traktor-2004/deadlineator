# Описание продукта

## Проблема

Команда теряет сроки, когда договорённости разбросаны по сообщениям и личным заметкам. Нужен один простой список задач с ответственным потоком, приоритетом и сроком.

## Цель и границы

| Цель | Критерий результата |
| --- | --- |
| Видеть все задачи | Список отображается на одной доске |
| Понимать срочность | У задачи есть приоритет и срок |
| Показывать ход работы | Статус можно менять между тремя колонками |
| Проверять качество | Все автоматические тесты проходят локально |

### В первой версии есть

- создание задачи с названием, сроком, приоритетом и командой;
- локальное хранение в JSON;
- доска «Бэклог / В работе / Готово»;
- API для чтения задач и смены статуса.

### В первой версии нет

- учётных записей и внешней базы данных;
- отправки писем и push-уведомлений;
- публикации приложения в интернете.

## Истории пользователей

1. **Как участник команды**, я хочу добавить задачу со сроком, чтобы не потерять договорённость.
2. **Как тестировщик**, я хочу переместить задачу в «Готово», чтобы показать результат проверки.
3. **Как преподаватель**, я хочу увидеть доску и локальный запуск приложения во время защиты.

## Критерий готовности

Задача считается готовой, если она работает в приложении, имеет тест или понятный способ проверки и не оставляет известных ошибок в консоли.
